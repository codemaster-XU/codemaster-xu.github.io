# Zongqi Xu · 许宗琦

[访问个人学术主页 / Visit my academic homepage](https://codemaster-xu.github.io/)

个人学术主页，展示研究方向、论文与研究稿件、工程实践、教育与学术合作、科研项目、专利申请、团队与创业经历、学术交流、课程、荣誉和技能。支持中英文切换和手机浏览。

新增章节目录、两条研究主线图、论文分类筛选、研究详解展开与收起、BibTeX 复制、阅读进度和打印布局。研究详解默认完整展开。

[下载公开学术简历 / Academic CV](assets/Zongqi-Xu-Academic-CV.pdf)

公开联系方式仅为学术邮箱。原始私人简历和个人隐私信息不包含在本仓库中。投稿、返修和专利申请均按实际状态标注；博士研究为未来目标。

## 更新内容

- `profile.js`：个人信息、论文状态、经历、项目、荣誉和公开联系邮箱。
- `index.html`：页面结构、首屏文字、链接和页面元信息。
- `styles.css`：配色、字体、间距和响应式布局。
- `app.js`：中英文切换与交互逻辑。
- `assets/`：照片、图标、链接分享预览图和公开学术简历 PDF。

修改文件并提交到 `main` 后，GitHub Pages 会自动重新发布。论文的录用、投稿与返修状态应随进展更新。修改个人资料后，也应同步更新公开学术简历 PDF 和页脚的更新日期。更换页面样式或脚本时，更新 `index.html` 中资源链接的版本号，确保访客加载新版本。

## 网站部署

本仓库为纯静态网站，无需安装依赖或构建。发布设置为 **Settings → Pages → Deploy from a branch → main → /(root)**。保留根目录的 `.nojekyll` 文件。

本地直接打开 `index.html` 即可预览。
